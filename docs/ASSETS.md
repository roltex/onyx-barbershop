# Assets and dependencies

- `public/interior.webp`: AI-generated editorial barber interior, created for this project. It does not document the real salon. Replace it with licensed photographs of Onyx before representing a physical location.
- `public/icon-192.png`, `public/icon-512.png`: Onyx monogram app icons generated locally.
- DM Sans and Manrope: self-hosted through `@fontsource` npm packages; upstream font licenses are distributed in their packages (SIL Open Font License).
- Lucide icons: `lucide-react`, ISC license, package license distributed with dependency.
- No fake reviews, star ratings, customer counts or awards are shown on the public site.
